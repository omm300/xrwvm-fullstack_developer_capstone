# fullstack_developer_capstone

## Project Name
**Full Stack Car Dealership Application**

## Repository Name
`xrwvm-fullstack_developer_capstone`

## Project Description
This project is a full-stack car dealership web application developed as part of the IBM Full Stack Developer Capstone Project. It uses Django for backend web functionality and provides pages for browsing dealership information.

## Technologies Used
- Python
- Django
- HTML and CSS
- JavaScript
- Git and GitHub

## Features
- Home page for the car dealership application
- About Us and Contact Us pages
- User login and logout functionality
- User registration interface
- Dealership information and reviews

## Run Locally
1. Open a terminal in the `server` directory.
2. Activate the Python virtual environment.
3. Run the Django development server using `python manage.py runserver`.
4. Open `http://127.0.0.1:8000/` in your browser.
